# Предсказание липофильности молекулы по ее SMILES

Модель предсказывает липофильность (LogP) молекулы на основе линейной записи структуры (SMILES).

## 📌 Задачи

- Разведочный анализ данных
- Стандартизация SMILES
- Построение новых признаков
- Обучение гибридной модели (DMPNN + MLP)

## 🗂 Структура проекта

- `preprocessing_smiles.ipynb` — анализ и стандартизация SMILES
- `preprocessing_data.py` — генерация признаков (дескрипторы, отпечатки, графы)
- `train.py` — обучение модели
- `predict.py` — предсказание липофильности по входному CSV
- `data/sample/` — примеры датасетов

## 🧠 Модель

Модель объединяет:
- DMPNN (DeepChem) для графового представления молекулы
- Полносвязные слои для обработки дескрипторов и фингерпринтов

## 🚀 Установка и запуск

1. Установите зависимости:

```
bash

pip install -r requirements.txt
```

2. Требуется Python версии `< 3.12`.

3. Обучение модели:

```
bash

python train.py
```

4. Предсказание на новых данных:

Новые данные должны быть стандартизированы с помощью `preprocessing_smiles.ipynb` перед предсказанием.

```
bash

python predict.py
```

## Использованные библиотеки

+ PyTorch, PyTorch Lightning
+ DeepChem, RdKit, Chython
+ Pandas, Numpy, Seaborn, Scikit-learn
